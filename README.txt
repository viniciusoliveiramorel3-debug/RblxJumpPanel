Rblx Jump Panel — código-fonte Android Studio, versão 1.1

Inclui painel externo preto/azul, gaveta recolhível, botão PULAR, ALVO reposicionável e LOCK/UNLOCK.
O botão PULAR envia um único gesto de toque pelo serviço de acessibilidade para o centro do ALVO.
O ALVO deve ser arrastado até o botão de pulo original do jogo. Use UNLOCK para mover e LOCK para travar.

Importante:
- Este arquivo é um projeto-fonte ZIP, não um APK instalável.
- Não foi possível compilar ou testar neste ambiente; a integração depende do Android e do jogo.
- Exige Android Studio + SDK para gerar APK, depois permitir sobreposição e ativar o serviço de acessibilidade.
- Algumas aplicações podem bloquear toques de acessibilidade/overlays ou desenhar controles de forma incompatível.
- O comportamento de pulo depende do jogo e do seu botão original; este app não altera a física nem concede pulo infinito.
